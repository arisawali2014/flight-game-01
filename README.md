**Skyharbor Run** — an original 3D flight game that plays offline in a desktop browser. Take off from Runway 36 on a harbour island, thread eight glowing rings on a circuit of the coast, the ridge and the town, then come home and land — graded on sink rate, speed and alignment, with centre bonuses for threading rings clean. A real little flight model (throttle makes speed, speed makes lift, bank makes the turn, and she stalls if you let her), fuel and damage to manage, a lit cockpit with an artificial horizon, needle dials and a compass tape, and WebAudio-synthesised engine, wind and warning sounds. Plain ES modules and a software 3D renderer on canvas, zero network requests, zero external assets.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve `out/game/` with any static file server, or play straight from the repo with `node serve.ts` and open http://localhost:8080.
